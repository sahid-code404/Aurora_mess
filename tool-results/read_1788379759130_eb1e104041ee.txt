     1→// =====================================================================
     2→// AURORA RESIDENCY MESS — Resident Meal, Finance & Operations Platform
     3→// Prisma schema (SQLite). Status enums are Strings (SQLite has no enums);
     4→// state transitions are validated in domain services (src/lib/domain).
     5→// MONEY RULE: every financial value is an Int in minor units (paise).
     6→// No mutable "balance" column — funds derive from the ledger.
     7→// =====================================================================
     8→
     9→generator client {
    10→  provider = "prisma-client-js"
    11→}
    12→
    13→datasource db {
    14→  provider = "sqlite"
    15→  url      = env("DATABASE_URL")
